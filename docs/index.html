Ship to CI

From clone to gated pipeline in minutes

No bespoke glue per endpoint. Export once, run everywhere JMeter runs.

01

Install

Python 3.11+. Yaymeter pulls portable JRE + JMeter on first run.

pip install -e ".[dev]"
02

Plan & export

Point at your spec and config. Commit the JMX like any other test asset.

yaymeter plan --spec openapi.yaml \
  --config my-api.yaml --out generated-tests/plan.json
yaymeter export-jmx --plan generated-tests/plan.json \
  --out generated-tests/plan.jmx
03

Enforce

Smoke on every PR; load on a schedule. Fail on JMeter exit code or coverage floor.

yaymeter run-jmx --jmx generated-tests/plan.jmx \
  --threads 1 --loops 1 --approve

Evidence testers trust

Reports and CI that speak QA language

PASS / FAIL / SKIP with paths to operations — plus untested endpoints and why. Metrics come from JTL and results.json, not LLM summaries.

.github/workflows/api-smoke.yml
name: API smoke
on: [pull_request]
jobs:
  yaymeter:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.11" }
      - run: pip install -e .
      - run: |
          yaymeter run-jmx \
            --jmx generated-tests/plan.jmx \
            --config my-api.yaml \
            --threads 1 --loops 1 --approve \
            --run-id ci-${{ github.run_id }}
        env:
          API_TEST_AUTH_TOKEN: ${{ secrets.API_TEST_TOKEN }}
